# Calculator Application

## Description

A Calculator application developed using Python and Tkinter. It performs basic arithmetic operations through a graphical user interface.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Percentage Calculation
* Square Root Function
* Backspace Button
* Modern Dark Theme Interface

## Technologies Used

* Python
* Tkinter

## How to Run

1. Install Python.
2. Download the project files.
3. Open the project folder.
4. Run:

python calculator.py
