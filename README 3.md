# Contact Book Application

## Description

The Contact Book Application is a Python-based project that helps users store and manage contact information efficiently. It provides an easy way to add, search, update, and delete contacts through a user-friendly interface.

## Features

* Add new contacts
* View all saved contacts
* Search contacts by name
* Update contact details
* Delete contacts
* Simple and easy-to-use interface

## Technologies Used

* Python
* Tkinter (GUI)
* SQLite (Database)

## How to Run

1. Install Python on your system.
2. Download the project files.
3. Open the project folder.
4. Run the following command:

python contact_book.py

## Project Objectives

* Manage personal and professional contacts efficiently.
* Learn GUI development using Tkinter.
* Understand database operations with SQLite.
* Improve Python programming skills.

## Future Enhancements

* Add profile pictures for contacts.
* Export contacts to CSV or Excel.
* Import contacts from external files.
* Add dark mode support.
